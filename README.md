# Continuity

*Password-Recoverable Authority over Threshold Signing Accounts*

Continuity is a Client-Server orchestration protocol for password-recoverable authority over threshold signing
accounts, in which provider-held state alone forms no signing quorum and recovery requires no pre-provisioned
user-held recovery material beyond a password.

> **Status:** This is a research draft shared for review. It is not a final specification and has not undergone
> independent security review.
